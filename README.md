# ⚡ THOR VIBES DISCORD MUSIC BOT
### *Command The Power • Hear The Rhythm*

A high-performance Discord Music Bot featuring Bassboost, 8D Audio, Slowed + Reverb, Nightcore, 24/7 Radio, Live Lyrics, Favorites, and Spotify & YouTube integration.

---

## 🌟 Key Features

- 🎵 **Spotify & YouTube Integration**: Single tracks, albums, playlists, or keywords.
- 🎛️ **Audio Filters & Equalizer**:
  - 🔊 **Bassboost** (`/bassboost <low|medium|high|extreme>`)
  - 🌌 **8D Audio** (`/spatial8d`)
  - 🌙 **Nightcore** (`/nightcore`)
  - 🌧️ **Slowed + Reverb** (`/slowed`)
  - 📻 **Vaporwave** (`/vaporwave`)
  - 🎤 **Karaoke** (`/karaoke`)
  - ⏩ **Speed Control** (`/speed <0.5x - 2.0x>`)
- 🔍 **Interactive Search Selector** (`/search <song>`): Choose from top 5 search results via Discord dropdown.
- 📻 **24/7 Lo-Fi & Radio Streams** (`/radio <station>`): Stream Lofi, Synthwave, EDM, Jazz, Rock, and Chill.
- ⚡ **24/7 Stay Mode** (`/stay247`): Keep the bot connected in voice channel 24/7.
- 📜 **Live Lyrics** (`/lyrics [song]`): Real-time lyrics lookup.
- ❤️ **Personal Favorites** (`/favorite add|list|play`): Save your favorite tracks directly in Discord.

## 📜 Full Command Reference

| Category | Slash Command | Description |
| :--- | :--- | :--- |
| **Playback** | `/play <query>` | Play from YouTube or Spotify |
| **Discovery** | `/search <query>` | Interactive Top 5 selection menu |
| **Controls** | `/pause`, `/resume`, `/skip`, `/stop` | Control music playback |
| **UI** | `/nowplaying`, `/queue` | View interactive player embed and active queue |
| **Audio** | `/volume <0-100>` | Adjust player volume |
| **Loop & Shuffle** | `/loop <off\|track\|queue>`, `/shuffle` | Repeat or randomize songs |
| **Equalizer** | `/bassboost <level>` | Boost bass frequencies (Low to Extreme) |
| **Effects** | `/nightcore`, `/slowed`, `/spatial8d`, `/vaporwave` | Toggle audio filters |
| **Speed** | `/speed <factor>` | Change playback speed (0.5x - 2.0x) |
| **Filter Reset** | `/filter_reset` | Clear all active audio filters |
| **Radio** | `/radio <lofi\|synthwave\|gaming\|chill\|jazz\|rock>` | Stream 24/7 live themed radio stations |
| **24/7 Mode** | `/stay247` | Toggle 24/7 voice channel stay |
| **Lyrics** | `/lyrics [song]` | Search and view song lyrics |
| **Favorites** | `/favorite add`, `/favorite list`, `/favorite play` | Manage personal saved tracks |
| **Utilities** | `/ping`, `/info`, `/help` | System stats and command guide |
